# 项目背景与范围

## 项目名称

浙江大学紫金港校区 WebGIS 信息点位展示与智能自习室推荐平台

## 背景

原始方案中包含校园导航、充电桩状态查询、自习室筛选、游客路线推荐等较多功能。根据当前大作业实际范围，项目收敛为一个可稳定完成和演示的 WebGIS 应用。

本项目重点体现：

- WebGIS 地图展示能力；
- 标准空间数据组织能力；
- 空数据兜底能力；
- GeoServer 对空间数据的管理；
- Cesium 对主题数据的三维展示；
- AI 对自习室需求的智能推荐；
- 优先通过 API 接入 ZJU-Charger 充电桩查询能力。

## MVP 范围

MVP 必须包含：

- 紫禁港校区二维地图浏览。
- 自习室点位数据展示，允许 demo 数据或空数据。
- 校园 POI 点位数据展示，允许 demo 数据或空数据。
- AI 自习室推荐查询。
- ZJU-Charger 充电桩 API 接入，iframe 备选，外链兜底。
- GeoServer 管理至少一类展示数据的方案或接入能力。
- Cesium 展示至少一类主题相关数据的方案或接入能力。
- 数据格式文档和空数据策略。

## 已取消功能

以下功能不做：

- 校园导航。
- 路线规划。
- 路径推荐。
- 一键导航。
- 游客推荐路线。
- 最近自习室定位推荐。
- 自习室筛选功能。
- 课堂汇报材料生成。
- 本地重新开发充电桩查询系统。
- 复制或改造 ZJU-Charger 大量源码。

## 成功标准

- 没有真实数据时页面仍能正常打开。
- 有 demo 数据时地图能显示 marker 和详情。
- AI 查询在有 API Key 时能推荐自习室，在无 API Key 或无数据时能给出清晰提示。
- ZJU-Charger API 不可用时，充电桩模块能显示兜底说明和外链。
- GeoServer、Cesium、ZJU-Charger 任一外部能力不可用时，核心页面不白屏。
- 项目文档能清楚说明范围、数据格式、运行环境和限制。
